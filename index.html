🔬 Análise Profunda (beta) roda em minutos, não em segundos

A análise instantânea acima roda no seu navegador e usa só fontes com acesso liberado a partir dele (API da Câmara, SICONFI, Agência Brasil). A Análise Profunda roda em um servidor do GitHub Actions e, por não estar limitada ao navegador, consegue:

  • usar dois modelos de IA locais (Qwen 3B como "cérebro" para redigir a narrativa, Qwen 1.5B como "subcérebro" para dar uma segunda opinião sobre cada promessa aceita ou descartada);
  • varrer mais feeds de notícia oficiais (Agência Brasil/EBC completa + Agência Senado), que o navegador não alcança por bloqueio de CORS;
  • demorar o que precisar — de 5 a 15 minutos, medido de verdade num run completo (551s incluindo o download dos dois modelos na primeira vez).
Limite honesto de hoje: por segurança, nenhuma página pública pode acionar direto um workflow do repositório privado — exigiria expor uma credencial no código do navegador, e isso nunca vai acontecer aqui. Por ora, quem dispara a análise profunda é o mantenedor do projeto, pelo GitHub Actions. O resultado, quando pronto, é publicado automaticamente e aparece aqui embaixo, na busca.
